# Arcade Plane

**Аркадный авиа-сборник с управлением перчаткой.**  
Две мини-игры, один контроллер — сжимай кулак, чтобы действовать.

---

## Игры

### Sky Dodge (Самолёт)
Уворачивайся от препятствий в небе. Штормы, птицы, НЛО, высотки — всё летит в тебя.
- Двигайся **вверх/вниз/влево/вправо**
- Накопи **1000 очков** — победи
- **3 жизни** (лампочки-индикаторы)
- При ударе — временная неуязвимость и мигание

### Ball Catch (Мяч)
Мяч летит с края экрана к кольцу. Поймай в нужный момент!
- Мяч меняет цвет: **красный → зелёный → красный**
- Сожми кулак когда мяч **зелёный** — +1 очко
- **10 попаданий** — победа
- Фидбек: *Perfect! / Great! / Good / Too bad!*

---

## Управление

| Действие | Перчатка | Клавиатура |
|---|---|---|
| Движение (самолёт) | Наклон руки | `WASD` / `↑↓←→` |
| Сжатие (меню + мяч) | Сжать кулак | `Enter` / `Space` |
| Калибровка | Раскрыть-сжать 5 раз | — |

Перчатка подключается по COM-порту и калибруется при запуске.

---

## Фичи

- **Параллакс-фон** — небо, город, дальние и ближние облака
- **Индикатор жизней** — 3 лампочки, общие для обеих игр
- **Тайминг-механика** — цветовой индикатор на мяче
- **Анимации врагов** — покачивание НЛО, тряска птиц, плавание туч
- **Очки и фидбек** — цветные оценки за каждое действие
- **Меню с логотипами** — on/off спрайты + свечение при выборе
- **Экраны победы и поражения** — раздельные для каждой игры

---

## Запуск

1. Открой проект в **Unity 6**
2. Открой сцену из `Assets/Scenes/`
3. Подключи перчатку к COM-порту (или играй с клавиатуры)
4. Нажми **Play**
